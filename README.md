# Ogarniacz (PWA)

Offline personal day organizer (PL/NL/EN): plan of the day, morning routine with timers, plan for tomorrow, lists tied to places with voice dictation, place reminders, supermarket on the route (OSM Overpass), household budget, and an 18+ medical-cannabis supply tracker (not medical advice).

All data stays in the browser (localStorage). No accounts, no backend.

Install on iPhone: open the page in Safari → Share → "Add to Home Screen".

Data sources: prices from [blisko-ceny](https://github.com/mikry119-cloud/blisko-ceny), maps © OpenStreetMap contributors (Nominatim, Overpass, OSRM).
